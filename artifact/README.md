# Artifact for the SPECops 2026 paper

This directory holds the **recorded run** that every number in the paper comes
from. It is evidence, not a dependency: nothing here is needed to *use* RuSmt on
your own language, only to check the numbers we report.

The split below follows one rule — **whatever the language model touched is
recorded here, and whatever is deterministic is regenerated by a command.**

## What is here (model-dependent, cannot be reproduced identically)

| Path | Contents |
|---|---|
| `suite/toml/` | The generated TOML conformance suite: 131 documents, one per covered marker, each named after the marker it reaches. This is the paper's deliverable. |
| `suite/imp/` | The 2 IMP witnesses, rendered from Z3's models back to IMP source. |
| `run/toml-markers.jsonl` | One line per marker (182 lines): the Stage-1 verdict, every Stage-2 round outcome, and the accepted witnesses. This is the marker-level ledger, including all 51 misses. |
| `run/toml-misses.txt` | The 51 uncovered markers, by name. |
| `run/toml-diff.json` | The differential result: per-input verdicts from all four parsers, their pinned versions, and the 15 divergences. |
| `llm-cache/` | 759 recorded proposer exchanges, keyed by a content hash of the prompt. Point `RUSMT_LLM_CACHE` here to replay the reported run without model access. |

Re-running the pipeline against a live model will produce *a* suite, not *this*
suite: the proposer is nondeterministic, so coverage and the divergence count
will move. That is why these files are committed rather than regenerated.

## What is not here (deterministic, regenerate it)

**The emitted SMT-LIB queries** (~75 MB). These do not involve the model or the
solver, so archiving them adds nothing. All 182 render in seconds:

```bash
RUSMT_SKIP_INVOKE=1 cargo run -p rusmt-smt-derive -- toml parse_toml
# -> lang/src/synthesis/toml/z3_chc/main.smt2 and target_<N>/main.smt2
```

**The conformance diff**, if you have the four runtimes installed. It is a pure
function of the suite, and re-running it reproduced `run/toml-diff.json` byte for
byte:

```bash
python3 conformance/diff.py artifact/suite/toml --json /tmp/toml-diff.json
```

## Reproducing the reported run

```bash
export RUSMT_LLM_CACHE=$PWD/artifact/llm-cache
export RUSMT_LLM_CMD=false          # every prompt should hit the cache
export RUSMT_ROUNDS=9 RUSMT_WITNESSES=1 RUSMT_Z3_SECS=15 RUSMT_STAGE1_SECS=2
python3 experiments/sweep.py toml parse_toml /tmp/toml.jsonl --jobs 6 --timeout 120
```

With `RUSMT_LLM_CMD=false` a cache miss fails loudly rather than silently calling
a model, so any divergence from the recorded run is visible rather than paid for.

Note that 26 of the 131 markers were covered by an earlier sequential
`cargo run -p rusmt-smt-derive -- toml parse_toml` pass that preserved the
accepted witnesses but not the per-round outcomes. Their witnesses are in
`suite/toml/`; their rows in `toml-markers.jsonl` carry
`"source": "sequential-top-level"` and no `round_outcomes`. The paper's proposal
audit covers the other 156 markers for exactly this reason.

## Environment of the reported run

Apple M1, macOS 26.5, Z3 4.15.4, proposer `gpt-5.4-mini`. Implementations tested:
Rust `toml` 1.1.3+spec-1.1.0, CPython `tomllib` (3.14.4), BurntSushi `toml`
v1.6.0, Node `smol-toml` 1.7.1.
