5 - future feature (upstream Z3?): Z3 has no parametric FUNCTIONS -- you can't write
    `(define-fun (par (T) ...))`, only parametric TYPES `(declare-datatypes ((F 1)) ((par (T) ...)))`.
    That's why we must monomorphize: emit one concrete `(define-fun foo_String ...)` per
    instantiation instead of a single generic template. If Z3 ever supported parametric
    define-fun, we could emit one template per generic function (like we already do for types)
    and drop the whole monomorphization-of-functions machinery.
